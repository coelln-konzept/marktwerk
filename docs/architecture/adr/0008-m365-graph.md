# 0008: Microsoft 365 via Graph application permissions

**Status:** proposed (implemented in M7 bridge / M10 inbox). **Needs the client's M365 admin.**

## Context
The company uses Microsoft 365. Research 03: EWS is being blocked/removed in Exchange Online
(Oct 2026 / Apr 2027); delegated-permission integrations (e.g. Zammad) break when the authorising
employee leaves and cause wrong-mailbox issues; forwarding-based tools move mail out of Outlook.

## Decision
Entra ID app registration with application permissions (`Mail.ReadWrite`, `Mail.Send`), **scoped to the
shared booking mailbox(es) with Exchange RBAC for Applications**. Webhooks + delta sync; mail stays in
Exchange; workflow state in marktwerk; replies sent as the shared mailbox.

## Consequences
- Needs a one-time setup by the client's M365 admin (app registration, RBAC scope, admin consent).
- The public webhook URL must be reachable (affects hosting/staging).
- Webhook subscriptions expire and must be renewed by the worker.
